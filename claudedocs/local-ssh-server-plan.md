# 本地 SSH/SFTP 服务

> 状态：当前实现与运维说明。服务实现在 `src-tauri/src/servers/ssh.rs`；本文不再记录已经完成的迭代阶段。

## 定位

Taomni 可以在应用进程内启动一个 SSH/SFTP 服务，适合临时远程终端、文件传输和端口转发。它使用应用配置中的凭据进行认证，不接入系统账号、PAM 或 OpenSSH 配置，因此不是系统级 SSH 守护进程，也不适合作为不受信任租户之间的安全隔离边界。

## 已实现能力

- 密码认证和 OpenSSH 公钥认证；可限制允许的用户名。
- 交互式 PTY shell、窗口尺寸变化、环境变量和 `exec` 请求。
- SFTP 文件列表、读写、创建、删除、重命名和元数据操作。
- 本地/动态/远程端口转发，对应 OpenSSH `-L`、`-D` 和 `-R`。
- 持久化 Ed25519 主机密钥及启动日志中的指纹。
- 最大已认证会话数、认证失败日志、连接生命周期审计和停止取消。
- Windows、macOS、Linux 使用各自的默认 shell 启动方式。

## 配置约定

通用监听地址、端口和启动/停止状态由服务器管理模块维护。SSH 专有字段位于服务配置中：

| 字段 | 含义 |
| --- | --- |
| `password` | 允许密码认证时的服务凭据 |
| `authorizedKey` | 单个 OpenSSH 公钥文本 |
| `authorizedKeyPath` | `.pub` 或 `authorized_keys` 文件路径 |
| `allowedUsers` | 可选的逗号分隔用户名限制 |
| `rootDir` | SFTP 根目录及 shell 初始目录；默认用户目录 |
| `loginShell` | Unix 上是否以 login shell 方式启动 |
| `maxSessions` | 最大并发认证会话数 |

密码和其他秘密应通过 Vault/安全配置路径保存，不应出现在文档、日志或导出文件中。未配置密码或公钥时服务拒绝启动。

## 文件与进程边界

SFTP 把客户端的 `/` 映射到 `rootDir`，当前词法路径检查会拒绝越过根目录的 `..`，并把客户端绝对路径重新映射到该根目录。但它没有对每次文件访问做 canonical/no-follow 校验，符号链接仍可能指向 `rootDir` 之外。shell 进程也只把该目录作为初始工作目录，并没有操作系统级 `chroot`/sandbox；获得 shell 权限的用户拥有 Taomni 进程账号本身可访问的系统权限。

因此：

- 只绑定确有需要的网卡；临时共享优先绑定回环地址。
- 使用强密码或专用公钥，并限制用户名。
- 不要把它暴露为互联网公共、多租户登录服务。
- 在符号链接边界修复前，不要把 `rootDir` 当作针对不受信任客户端的文件系统安全边界。
- 远程转发可能把监听端口暴露到非本机地址，启动日志会提示该风险。

## 主机密钥与审计

首次启动生成主机密钥，后续启动复用，以避免客户端指纹无故变化。迁移应用数据目录或删除密钥会改变指纹；这类操作必须作为显式运维事件通知使用者。

日志记录连接来源、认证结果、用户名、认证方式、会话时长、转发监听和服务停止等事件，不记录密码、私钥内容或 SFTP 文件内容。

## 验证

变更至少覆盖：

- 密码、公钥、错误用户和无认证配置。
- 交互 shell、`exec`、终端 resize 和断开清理。
- SFTP 正常路径、`..`、绝对路径和大文件读写；符号链接逃逸在修复前保留为明确的安全门禁。
- `ssh -L`、`ssh -D`、`ssh -R` 的建立、传输和取消。
- 最大会话数、重复启动、端口占用及应用退出清理。
- Windows、macOS、Linux 的原生客户端互通。

Rust 单元测试可随日常 `cargo test --lib` 运行；网络互通和平台 shell 行为仍需原生环境验证。
